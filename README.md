# SUDATA x SUBAA 2025 Datathon

Optimisation of supply chain operations, using time series analysis and forecasting.

## Overview

- This repository contains code and analysis for our **1st place** submission to the **SUDATA x SUBAA 2025 Datathon**.
- My contribution applies **ETS forecasting**, **hierarchical forecast reconciliation**, and **optimisation techniques** in **R** to a supply chain management setting.
- It includes data preprocessing, exploratory analysis of delivery delays, and modelling workflows aimed at improving forecasting and operational planning.

## Repository Structure

- `Calvin/`: my contributions, which involve time series forecasting using ETS, as well as forecast reconciliation.
- `Lyra/`: my group member's contributions, which involve optimisation methods to reduce costs.
- `Shane/`: another one of my group member's contributions.
- `Other Resources/`: a small folder of notes on ARIMA and LSTM that we read up on prior to starting the competition.

## Results

- Proposed strategy focusing on on-time deliveries.
- Achieved a simulated 53% reduction in overall operational costs.

## Tools

- R: tidyverse, tidyverts
- Python: numpy, pandas, scikit-learn
